# Security Policy

We take security seriously at FlexAgent. If you discover a security vulnerability in this project, please report it immediately according to the guidelines below.

---

## Supported Versions

Only the latest active release version receives security updates.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | ✅ Yes     |

---

## 🔒 Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub Issues.**

Instead, please send an email to the repository maintainer (or the email listed in the GitHub profile). We will acknowledge receipt of your vulnerability report within 48 hours and work with you to analyze and resolve the issue.

We appreciate your responsible disclosure and will give appropriate credit in our release notes once a fix is published.
